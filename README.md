# Butterfly LAN OTA entry

这个仓库是仿生蝴蝶 ESP32-C6 控制台的公开入口。GitHub Pages 提供静态页面；实际控制和固件传输在手机与开发板的同一局域网内完成。

## 使用

1. 使用原网页 OTA 安装带 AP+STA 配网功能的固件。
2. 首次连接板子热点，在板子网页的「连接家里的 Wi-Fi」中配置 2.4GHz 路由器。
3. 手机切回同一路由器，访问本入口，填写板子获得的局域网 IP，打开控制台。

公开页面不会直接跨源请求私网 HTTP API，不需要浏览器放宽混合内容或 CORS。它导航到板子提供的完整界面。仅将旧版页面复制到 GitHub 不会让旧固件自动联网。

不包含路由器密码、设备凭据、固件二进制或远程中转服务。固件需由项目维护者提供；上传百分比不代表升级成功，以设备重启确认结果为准。
