蝴蝶 · 无线升级

手机和板子连接同一个路由器，就能打开板子的控制台。无需切换到板子热点。

打开你的板子

从板子网页的“连接家里的 Wi-Fi”中查看，或在路由器的设备列表中找到 butterfly-c6。地址可能随路由器重新分配而改变。

打开后可以查看开机时间、切换呼吸灯／常亮灯，并选择应用 firmware.bin 升级。

第一次配置

  1. 先用原网页 OTA 安装支持路由器联网的新固件。已经支持网页升级的板子无需重新接烧录线。
  2. 连接 Butterfly-C6-WiFi，打开 192.168.4.1，在“连接家里的 Wi-Fi”中填写路由器的 2.4GHz Wi-Fi 名称与密码。
  3. 等页面显示局域网地址，记下它。将手机切回同一个路由器，再通过上面的入口打开板子。

如果局域网无法访问，请检查是否使用了访客 Wi-Fi 或开启了客户端隔离；板子原热点仍保留，可用于排查和重新配网。

这是 GitHub 上的公开入口，实际操作将在板子的局域网页面完成。入口不会上传固件，不收集 Wi-Fi 密码，也不会从公网探测你的板子。此方案用于同一局域网；不提供跨互联网远程控制。
